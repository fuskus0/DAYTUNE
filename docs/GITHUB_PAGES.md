# GitHub Pages
1. Crea un repositorio público. 2. Sube el CONTENIDO de la carpeta daytune a la raíz (index.html debe quedar en la raíz).
3. Settings > Pages > Deploy from a branch > main /(root) > Save. 4. Tras 1-2 min: https://USUARIO.github.io/REPO/
Si cambias archivos, sube la versión de caché en sw.js (dt-2 > dt-3) para que los móviles se actualicen.
