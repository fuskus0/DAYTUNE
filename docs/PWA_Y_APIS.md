# Instalar como PWA
Android/Chrome: abre la URL HTTPS > menú > Instalar aplicación. iOS/Safari: Compartir > Añadir a pantalla de inicio. PC Chrome/Edge: icono de instalar en la barra de direcciones.
# APIs
Clima: Open-Meteo (forecast + geocoding), gratuito, SIN clave. Supabase: ver SUPABASE.md.
# Segundo plano
Android/Chrome: suele seguir sonando con la pantalla bloqueada y muestra controles multimedia. iOS: Safari/PWA puede pausar el audio al bloquear o cambiar de app, sobre todo durante crossfades; no hay solución web fiable.
